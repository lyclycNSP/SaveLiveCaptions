# v1.4.0：统一单文件便携版

下载 **SaveLiveCaptions.exe**，双击即可使用，无需安装程序或 Python。**SHA256SUMS.txt** 用于校验下载文件。

## 更新

- 合并原单文件版和自动启动文件夹版，只保留一个 EXE。
- 启动时自动检测 Windows 实时字幕，仅在未打开时发送 Win + Ctrl + L，避免关闭已有窗口。
- 自动启动在工作线程执行，初始化期间禁用录制按钮；失败会提示手动打开后重试。
- 标题栏和任务栏使用程序图标，图标资源随 EXE 一起打包。
- 删除独立 WithLC 启动入口、Inno Setup 安装脚本及对应构建流程。
- 移除未使用的函数、状态、缓存配置和历史字节码；构建与发布流程统一。
- 用中文 README 替换原说明，插图更新为当前便携程序的真实截图。

保留上一版的分段录制、停止并保存、关闭确认、最小化后台录制、启动历史排除，以及字幕顺序和短句等修复。

## 使用

等待程序显示“准备就绪”，点击“开始录制”并选择保存文件夹，再播放要记录的内容。点击“停止并保存”后可直接开始下一段；退出使用标题栏关闭按钮。

需要 Windows 11 的实时字幕功能可用，首次使用可能需要先完成系统字幕语言设置。新旧文本分界以首次成功读取为准，无法精确对应音频帧；任意识别改写及相同画面中的重复发言仍可能无法可靠区分。

## 验证

本地 Python 3.11 环境下 58 项 unittest、mypy（11 个源文件）及 flake8 检查通过。测试包含真实 Tk 窗口和模拟的字幕/自动启动流程；便携 EXE 的启动、自动打开系统字幕、最小化、恢复和正常退出已检查。长时间真实语音及跨显示器 DPI 手动操作尚未验收。
