# v1.3.0 历史发布记录

此记录仅对应已发布的双版本；当前统一便携版的使用及构建方式见 [README](../../README.md)。

## 下载

- **SaveLiveCaptions_SingleFile.exe**：单文件便携版。先用 Win + Ctrl + L 打开 Windows 实时字幕，再启动程序。
- **SaveLiveCaptions_LCautostart_Folder.zip**：自动打开实时字幕的便携版。完整解压后运行其中的 EXE。

## 本版更新

- 使用 Windows 标准标题栏，支持任务栏显示、最小化、最大化和关闭；最小化不影响录制，拖动由系统处理。
- “停止并保存”仅结束当前段，可直接继续录制下一段，每段创建独立 TXT。
- 录制中关闭会确认；确认后保存再退出，保存失败报错并保留窗口。
- 每段开始时排除实时字幕已有文本，持续处理旧内容滚动和旧尾句扩写，只保存新增部分。
- 修复小数拆句、数字归一化、中文/短句漏存、字幕顺序、合法重复内容误删及停止尾句遗漏。
- 将 UI Automation 读取放入独立 COM 线程，减少界面卡顿；文件更新采用原子替换。
- 修复自动启动快捷键可能关闭已打开的实时字幕的问题。

数字归一化实现采用上游 [PR #22](https://github.com/LiveCaptionsHelper/SaveLiveCaptions/pull/22) 的 MIT 代码；小数问题参考 [PR #21](https://github.com/LiveCaptionsHelper/SaveLiveCaptions/pull/21) 的分析。

## 验证与限制

本地 Python 3.11 环境下 53 项自动测试、mypy 和现有 flake8 检查通过；两种便携包构建成功，单文件 EXE 启动、退出已验证。自动测试包含真实 Tk 窗口和模拟字幕流。

建议先开始录制，再播放下一段。历史排除以连接后首次成功读取为准；任意识别改写、相同画面中的重复发言及跨显示器 DPI 行为仍有限制。长时间真实语音与安装/卸载尚未人工验收。完整说明见仓库的 docs/code-review.md。
