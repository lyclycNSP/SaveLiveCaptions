# Save Live Captions v1.4.1

修复录制过程中整段字幕反复写入 TXT 的问题。保存引擎改为维护已滚出的正文和当前可更新的字幕草稿，窗口内的识别更正更新对应位置，不再追加成多次发言。

- 处理历史段落中间改写、末句持续扩写、数字识别更正和标点重新断句。
- 处理滚动首句截短与临时只读取到画面前缀的情况；保留后来真实重复出现的发言，不做全文件去重。
- 正常新增走追加路径，草稿更正通过临时文件原子替换；写入失败不推进保存状态。
- 录制期间保持亮屏并阻止自动睡眠，停止或异常后恢复原线程电源要求，不修改系统电源计划。
- 移除旧末行替换实现及不再使用的 aiofiles 依赖。

下载 **SaveLiveCaptions.exe** 后双击运行，无需安装 Python 或安装程序。`SHA256SUMS.txt` 用于校验下载文件。

本地 87 项测试、类型检查和 lint 通过；用户已确认本轮修复解决其遇到的重复问题。时间戳仍是程序观察时间，无法用于证明音频完整转录；黑屏、手动锁屏或睡眠中的录制不在本次保证范围内。
