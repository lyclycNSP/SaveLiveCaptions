# 实现与验证说明

当前使用单一源码入口 `src/main.py`，构建结果为 `dist/SaveLiveCaptions.exe`。用户操作、运行和构建命令以 [中文 README](../README.md) 为准。

## 执行路径

1. `main.Dashboard` 创建带系统标题栏和任务栏入口的 Tk 窗口，在后台初始化 Windows 实时字幕。
2. `function.livecaptions.ensure_live_captions` 在工作线程中检测系统窗口，仅在未打开时发送快捷键并等待窗口出现。失败回传界面，不阻塞 Tk；可手动打开后开始录制。
3. `function.texthook.hook` 在单独的 COM 线程读取字幕，初始化、控件释放及反初始化均在该线程完成。`CaptionReader` 通过 `function.power.RecordingPowerGuard` 在同一线程申请、释放 `SetThreadExecutionState` 电源请求；录制期间保持亮屏和系统运行，结束时恢复该线程原来的要求，不更改电源计划。初始化失败也进入清理，COM 清理失败仍释放电源请求。
4. `function.baseline.StartupBaseline` 排除开始时已有内容，处理后续滚动与原文扩写。每段录制独立建立基线。
5. `function.sentences` 统一解析小数、地址及中英文断句；`function.capture.CaptionSession` 对齐相邻快照，维护已滚出正文和仍可更正的字幕窗口。已对应的句子沿用出现时间，改写区段更新当前版本。
6. `function.save.TranscriptStore` 保存正文的字节边界和已发布草稿。正常增长验证文件尾部后追加，写入异常回退到原长度；草稿更正逐块复制正文、写新草稿、fsync 后原子替换。成功写入后才推进边界和会话状态，不在内存累计整场转录。

停止与关闭独立：停止等待尾句落盘后恢复开始按钮；录制中关闭须确认，并等待保存结束。保存失败会保留窗口并提示。最小化不改变录制状态。

## 保真与局限

不进行全文件模糊去重。窗口内保留的是当前识别版本，连续观察阈值只控制展示时机，不再代表内容不可修改。上下文对齐后的改写区段可更新数字、文字和标点；无对应上下文的不同数值不通过模糊相似度合并。英文数字归一化只用于比较，TXT 保留识别原文。

早期实现只允许更新末句，历史任意位置变化都会使整段匹配失效；上一轮只拆分末句仍不足以解决中间句子改写。本次使用句子重叠和唯一句子的有序锚点对齐，匹配复杂度 O(n log n)。扩展对齐至少需要两条匹配，避免单个偶然相同的短句造成旧文丢失；无可靠对应时保留旧窗口后另记新内容。滚动截断首句时保留先前读到的完整文字，临时前缀采样不清空窗口。

正文在窗口滚动时提交，窗口内改写覆盖草稿，不把多个识别版本追加成多次发言。停止时发布完整草稿，包括短尾句。历史排除依赖相邻画面的文字重叠；首个成功读取定义新旧截止点，历史恢复、失去上下文的整窗改写和相同画面下的重复发言仍可能无法可靠区分。当前没有音频、逐条识别事件、精确时间码及自动重连。

2026-10-23 的 22:11 样本未熄屏仍记录 1223 行，在 22:12:44 同秒记入 31 行，其中 29 行曾出现；块内可见中间数字识别结果交替。测试固定复现了中间改写、反复更正、首句截断和临时前缀导致的整段重放。另抽取 13 个大批次尝试重建画面，但同秒批次可混有旧尾句落盘，拼接后会产生原画面未必存在的句子，因此不将该实验作为真实快照回放或完整性验收证据。

此前两份样本分别为 999 行/591 秒与 183 行/417 秒，曾怀疑熄屏有关；新证据说明熄屏不是必要条件。保持亮屏按用户偏好保留，但不作为重复问题的根因修复。TXT 不能区分字幕提供端、UIA 和 GUI 事件循环的延迟，黑屏状态仍未验收。

电源请求采用微软文档的 `ES_CONTINUOUS | ES_DISPLAY_REQUIRED | ES_SYSTEM_REQUIRED`，恢复使用 API 返回的原状态。手动锁屏、屏幕保护程序、合盖及用户发起的睡眠不由此保证。参考 [SetThreadExecutionState](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-setthreadexecutionstate)。

系统字幕窗口存在并不代表首次语言配置已完成。自动启动失败、字幕控件变化、输出文件锁定或磁盘写入错误均需在实际环境排查。不要在录制中编辑输出文件。

## 冗余清理

统一自动启动逻辑到主程序，移除独立 WithLC 入口与安装脚本。工作流和构建脚本只生成一个便携 EXE；历史 [v1.3.0 发布说明](releases/v1.3.0.md) 仅说明旧版分发。

移除无人读取的近期字幕缓存及其配置、空的关闭文件兼容函数、未使用的句子筛选方法和重导出。保留会话、解析、数字比较及其测试。Python 字节码、构建目录和本地虚拟环境均不应进入 Git。

## 验证边界

测试覆盖字幕解析、顺序、短句、重复出现、历史排除、失败写入、连续录制、关闭确认、最小化恢复及自动启动的成功/失败路径。UIA 流和快捷键调用在自动测试中被模拟，不代表真实语音或快捷键已经验收。

最终便携 EXE 的启动、资源加载、正常退出与实际界面截图另行检查。长时间真实语音、跨屏 DPI 手动拖动及远程 GitHub Actions 不属于本地测试结论。
