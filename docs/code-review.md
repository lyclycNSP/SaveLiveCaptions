# 代码审查与修复说明

检查范围：两个 Python 启动入口、全部 function 模块、依赖、GitHub Actions 和安装脚本。未更改运行依赖版本和 TXT 时间戳格式；本次修复纳入 v1.3.0 发布。

## 追加交互修改

窗口现在使用系统标题栏及普通任务栏入口，支持最小化、最大化、恢复、关闭；拖动交给 Windows，不再使用自绘浮窗拖动。保持置顶属性，最小化时后台录制继续。

“停止并保存”只停止当前段，等待尾句写入后恢复开始按钮，下一段创建新文件并复用已选文件夹。保存期间阻止重复开始。只有标题栏关闭或 Alt + F4 触发退出，录制/保存中先确认；取消不改变录制状态，确认后等待保存完成。保存失败报错并保留窗口。Esc 不再退出。

## 启动历史过滤

每段开始后，首次成功读取 Windows 字幕控件时建立基线，该次内容不写入。后续使用剩余旧文本与当前画面前缀的重叠持续排除历史，并处理短暂的前缀快照；旧内容消失后释放基线。旧尾句继续扩写只保存追加字符，停止 flush 同样不会补写被排除的历史。

这不是音频时间边界：连接完成前已经生成的文字会进入基线，应先开启录制再播放下一段。采样中若旧内容被任意识别改写、历史突然恢复或新旧文字完全相同，无法保证精确区分；基线主要覆盖稳定历史、原文扩写和正常滚动，不清空 Windows 字幕。

新增的基线与 hook 集成测试覆盖静止历史、短暂布局、空画面、滚动、扩写、没有新增就停止、下一段重新建立基线。

本次共 53 项 unittest 通过，mypy（10 个源文件）及现有 flake8 检查通过。两种 Windows 包重新构建成功，单文件 EXE 启动/退出码 0，归档中确认包含 function.baseline；未运行真实语音录制。

## 发现与处理

| 问题 | 影响 | 处理 |
| --- | --- | --- |
| 用 set 遍历字幕 | 字幕写入顺序不确定，相同短句合并 | 按出现顺序对齐相邻字幕快照，保留每次出现 |
| 中文完整句被判为未完成、过滤短句 | 中文和 “Yes.” 等短句丢失 | 修正中英文边界，保留有文字或数字的短句 |
| 全会话 seen 集合、退出全局模糊去重 | 合法重复被误删、长录制内存/清理成本增长 | 会话状态局部化，不再全局清理字幕文件 |
| 退出逻辑另用标点正则切尾 | 小数/网址再次拆错、漏存尾句 | 运行与退出共用解析结果，按序 flush |
| 模糊相似句包含不同数字 | 可能丢失不同数值的事实 | 数字不同不合并，仅保守更新当前扩写尾句 |
| 更新文本先改内存再写文件 | I/O 失败后状态与文件不一致 | 成功写入后再更新状态；替换末行使用同目录临时文件及原子替换 |
| 同秒文件名冲突、多余常驻句柄、第二个 Tk 根窗口 | 多次录制混入同文件、资源管理复杂 | 排他创建唯一文件，写入独立关闭，对话框复用主窗口 |
| 录制异常只打印终端 | windowed EXE 中静默停止 | 界面显示错误，允许重新开始 |
| UIA 搜索/读取阻塞 Tk | 拖动及按钮可能卡顿 | 单独线程执行 UIA，COM 初始化与释放在同一线程 |
| 拖动基于移动窗口内的局部坐标 | 窗口反复反馈移动、按钮事件误触拖动 | 最终采用系统标题栏，由 Windows 处理拖动，按钮不绑定拖动 |
| 关闭后 Tk 定时回调 | TclError | 等待字幕 flush，再取消回调并销毁窗口 |
| 自动启动快捷键实际为切换 | 已开启的实时字幕被关闭 | 检测到字幕已开启时不发送快捷键 |
| Release 引用没有生成的 autostart EXE | 自动启动版本无法下载 | 打包现有 onedir 为 ZIP，并附安装程序；添加回归测试步骤 |

## 已知限制及后续建议

- 这是 Windows 实时字幕界面采样，不是识别引擎的逐条结果事件。如果同一句连续重复但屏幕文字完全没变化，无法可靠区分重复发言和未更新画面。
- 尾句修订仅处理可确认的前缀扩写；任意识别改写、重新断句可能保留两个版本。这比错误删除内容更保守；可进一步增加可选原始快照日志，凭真实录制样本改进对齐。
- 仍依赖 Windows 的 UIA 类名与 AutomationId；系统升级可能改变结构。目前断开会保留已抓取尾句并报错，未自动重连。可以后续增加暂停/继续、自动重连和计数，但应先用真实字幕流验收。
- 原子替换可能被同步软件或用户编辑器锁定；失败会报错，原文件保留。不要在录制中手动编辑输出文件。
- 未对已打包发布的旧 EXE、Inno Setup 安装/卸载或 GitHub 实际发布进行验收。最终版本已做真实 Tk 系统标题栏样式及最小化/恢复测试；跨显示器 DPI 切换、连续手动拖动和长时真实语音仍需人工确认。
- 安装脚本将中文选项指向默认语言文件，未在本次修改，后续可在 Inno Setup 环境确认语言资源并修正。
